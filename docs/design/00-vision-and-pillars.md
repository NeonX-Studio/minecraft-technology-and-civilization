# 00 · 愿景、设计支柱与决策记录

## 1. 一句话愿景

**在一颗程序生成、遵循地球规律的星球上，带领一个部族从打制石器走到火星殖民；世界会记住你建过的每一条路、砍过的每一片林、救过或背叛过的每一个邻国。**

## 2. 玩家幻想

| 阶段 | 玩家感受 | 支撑系统 |
| --- | --- | --- |
| 开局 | “我和四个族人站在一条陌生的河边，必须决定在哪里过冬。” | Wildlands 地理、Settlements 部族、Atlas 记忆地图 |
| 早期 | “这片河谷的土适合种谷子，上游的山里有铜。” | Cultivation 土壤、Wildlands 地质、Discovery 观察 |
| 中期 | “我的水车带动了磨坊，商队沿着我修的路把面粉卖到海边。” | Industry 动力、Networks 道路、Exchange 商队 |
| 中后期 | “邻国用更便宜的铁冲击我的市场，我要么结盟，要么修城墙。” | Nations 外交、Exchange 价格、Frontiers 威胁 |
| 后期 | “工厂让城市繁荣，也让下游的鱼死光了，我必须立法治理。” | Industry 污染、Ecology 演替、Commons 政策 |
| 终局 | “我在月球基地上用卫星地图俯瞰整颗星球，地图上每一条线都有我的历史。” | Orbit 太空、Atlas 卫星图层、Echoes 历史 |

## 3. 设计支柱

### 支柱 1：世界是真实的系统，而不是背景板

- 地形、气候、流域、矿床遵循简化但一致的地球物理规律：板块边界产生山脉与火山，雨影产生沙漠，河流从高处流向海洋。
- 每一项资源的位置都能被解释：锡出现在花岗岩侵入体附近，石油出现在沉积盆地，煤出现在古代沼泽地层。
- 玩家通过观察与测绘**理解**世界，而不是查表。

### 支柱 2：文明会记住你

- 道路、建筑、砍伐、污染、战争、条约都会写入文明记忆与世界历史。
- 已灭亡的古文明留下可解读的遗迹；玩家自己的文明也会在世界历史中留下记录。
- NPC 记得谁帮助过他们，AI 文明记得你违背过的条约。

### 支柱 3：可见的过程，而非菜单数字

- 工业用传动轴、齿轮、管道、传送带和多方块机器实际运转。
- 贸易由真实的商队、船和火车在地图上运输。
- 研究需要在实验台、观测站和图书馆中实际进行。
- 菜单用于**规划和监控**，不用于替代过程。

### 支柱 4：独立有趣，联合更深

- 每个主题模组单独安装时有完整乐趣；只依赖必要的核心库。
- 多个模组同时安装时出现新机制，而不是简单加数值。
- 每个联动都是双向的，并在 [34-interaction-matrix.md](34-interaction-matrix.md) 登记。

### 支柱 5：文明层面的选择，而不是个人生存的苦役

- 不加入口渴、体温、疾病等个人生存条。玩家的“生存压力”来自聚落：食物供应、住房、秩序、外部威胁。
- 玩家是领袖、工程师、探险家和科学家，而不是单纯的劳动力。
- 个人技能提供效率和专精，但不阻挡文明进度。

### 支柱 6：每个时代都有新的玩法动词

- 时代推进不是“同一件事更快”，而是解锁新的动词：定居、冶炼、航海、机械化、电气化、飞行、计算、发射。
- 每个时代必须新增至少一个空间尺度（营地 → 河谷 → 地区 → 大陆 → 海洋 → 全球 → 轨道）。

### 支柱 7：后果可逆，但需要代价

- 污染、砍伐、过度捕捞、战争都会造成长期后果。
- 后果可以通过科技、政策和公共工程逆转，但需要时间、资源和政治代价。
- 不设计“无法挽回”的永久惩罚，除非玩家主动选择（例如核战争的极端后果仍可在数十年游戏内恢复）。

## 4. 反支柱（明确不做）

| 不做 | 理由 |
| --- | --- |
| 个人生存条（口渴、体温、疾病、精神值） | 用户决定只做文明层面 |
| 无限收购的统一商店 | 违背区域经济设计 |
| 纯数值的“更高级机器 = 更快” | 违背支柱 6 |
| 魔法主线 | 主线写实；异界 Beyond 是可选支线 |
| 星际旅行与外星文明 | 太空时代止于近地太空、月球、小行星与火星 |
| 原版村民交易 | 原版村庄被自有 NPC 与势力替代 |
| 原版工具与机器的捷径合成 | 大部分原版工具合成被移除，走模组科技线 |
| 强制全家桶 | 主题模组只依赖必要核心库 |

## 5. 体验目标

| 指标 | 目标 |
| --- | --- |
| 标准通关时长 | 约 407 小时（范围 300-500 小时） |
| 首个永久定居点 | 实时 2 小时内 |
| 首次时代跃迁（E0 → E1） | 实时约 4 小时 |
| 首次遇到 AI 文明 | E2 前（约 20-35 小时） |
| 首次自动化生产线 | E4 水力磨坊（约 60-90 小时） |
| 每个时代至少新增 | 1 个新玩法动词、1 个新空间尺度、1 个新地图能力、3 个以上新 NPC 职业 |
| 单人世界中同时实体化 NPC | 最多 500 |
| 中高端硬件帧率 | Complementary 光影 + 写实 PBR 下 60 FPS 以上（RTX 3070 级） |
| 服务器 tick | 典型场景平均 MSPT ≤ 35 ms |

| DR-02 | 多人关系 | 所有玩家同属一个玩家文明，合作发展 |
| DR-03 | 时代跨度 | 石器时代 → 太空时代 |

| DR-30 | 性能 | 中高端单机：约 500 名实体 NPC；远处文明抽象模拟；全局人口可达数万 |

## 8. 范围边界

### 8.1 本设计范围内

- 18 个模组的玩法、内容、数据、接口、UI、美术规范与数值。
- 原版内容的移除、替换与重做规则。
- 单人与多人（同一玩家文明）的完整体验。
- Sodium、Iris 与 Complementary Reimagined 光影兼容。

### 8.2 本设计范围外

- 第三方大型科技或魔法模组（如 Create、Mekanism、Ars Nouveau）的官方兼容。可以作为未来兼容层，但不是设计前提。
- 星际旅行、外星文明、外星生命主线。
- 多个玩家文明之间的 PvP 竞争（DR-02 已决定合作）。
- 移动平台、基岩版。
- 第三方贴图包（如 Patrix）资产的再分发；只参考风格。
